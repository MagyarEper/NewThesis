# final/irodalom/ — Áttekintő

Ez a mappa a `02_irodalom.md` hiányzó szekciójainak vázlatait tartalmazza.  
Minden fájl egy-egy témát körvonalaz: mit kell lefedni, milyen irodalmat kell megkeresni, hova kell beilleszteni.

## Fájlok

| Fájl | Téma | Beillesztés helye | Prioritás |
|------|------|-------------------|-----------|
| [01_mel_spektrogram_stft.md](01_mel_spektrogram_stft.md) | Mel-spektrogram, STFT, log-mel | 2.1 vagy 2.2 elejére | LEGFONTOSABB |
| [02_transformer_architektura.md](02_transformer_architektura.md) | Transformer encoder-decoder, self-attention | 2.3 ASR szekció eleje | KÖZEPES |
| [03_speaker_embedding.md](03_speaker_embedding.md) | d-vector, x-vector, TTS kondicionálás | 2.2 Grad-TTS szekció | KÖZEPES |
| [04_g2p_szoveg_elofeldolgozas.md](04_g2p_szoveg_elofeldolgozas.md) | G2P, CMU korlátai, espeak-ng, basic_cleaners | 2.2 TTS pipeline szekció | KÖZEPES |

## Munkafolyamat

1. Minden fájlban van egy **„Ajánlott irodalom"** táblázat — ezeket kell megkeresni és elolvasni
2. A vázlat alapján megírod a szekciót (300–500 szó/téma)
3. Beilleszted a megfelelő helyre a `02_irodalom.md`-be
4. A forrásokat hozzáadod az irodalomjegyzékhez
